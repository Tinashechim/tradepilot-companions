# TradePilot 1.0.39.0

Position Sizer shows the selected Risk input with the other cash, percentage and 1R equivalents beside it on both MT4 and MT5. The input shares the Entry Price and Stop Loss left edge. Equivalent text sizing no longer uses a height that forced it into tiny text. Values use the connected account current balance and account currency; 1R is the entered planned cash risk.

The bundled Admin Guide explains the Risk row and equivalents. All features from 1.0.38 remain included: one automatic-email opt-out, reordered account actions and clickable Admin Guide contents with Account Setup first.

Both native companions compile with zero errors and warnings. Regression results and package contents are verified separately. Native final visual confirmation, Store-signed startup and broker execution remain pending. Existing trading permissions, account configuration, payments and positions are preserved.
