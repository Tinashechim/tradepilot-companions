Author and version are retained on sign-in and the main desktop footer, and removed from Settings subsections. MT4 and MT5 Apply wins and Apply losses buttons remove bracket marks while retaining centred wording, colour states and existing behaviour.

SL LINE and SPREAD share the 130×20 button dimensions and common Arial font with APPLY WINS and APPLY LOSSES. Companion visual review comes before the desktop app update.

The two UPDATE buttons, Target/Limit/Risk Mode button values, and Point Measurer SPREAD ON/OFF and POTENTIAL captions are uppercase. Button colours and calculations retain their existing meaning.
